# Лабораторная работа №5: Git и GitHub. Совместная работа, создание Pull Requests

## 📌 Описание проекта
Данный репозиторий создан в рамках выполнения лабораторной работы по дисциплине, посвящённой командной разработке с использованием распределённой системы контроля версий **Git** и платформы **GitHub**.

В ходе работы отработаны ключевые навыки:
- создание тематических веток (`feature branches`) и управление ими;
- командная работа над общими файлами проекта;
- оформление, рецензирование (Code Review) и слияние **Pull Requests (PR)**;
- моделирование и успешное локальное разрешение **конфликтов слияния (Merge Conflicts)**.

2. **Задание 1: Работа с ветками**:
   - Созданы ветки `feature-daniil` и `feature-tatiana`.
   - Добавлены индивидуальные файлы `daniil.txt` и `tatiana.txt`.
   - Оформлены Pull Requests (#1 и #3), проведены Code Review и слияния в `main`.
3. **Задание 2: Совместная работа**:
   - Создан общий файл `team.txt` с описанием участия каждого члена команды.
   - Оформлен Pull Request (#2) и интегрирован в основную ветку.
4. **Задание 3: Моделирование и разрешение конфликта слияния**:
   - Созданы ветки `feature-daniil-conflict` и `feature-tatiana-conflict`, в которых одновременно модифицированы одни и те же строки в `team.txt`.

   - Конфликт был успешно разрешен локально при помощи `git merge main`, удаления маркеров `<<<<<<<`, `=======`, `>>>>>>>` и последующего пуша.

5. **Задание 4: Итоговое оформление**:
   - В ветке `feature-readme` оформлен файл `README.md`.
   - Создан финальный Pull Request и объединены все наработки в `main`.
